- 4,517 from osrsreboxed-db (https://github.com/0xNeffarion/osrsreboxed-db, docs/items-icons/{id}.png, commit 37322fed3abb2d58236c59dfc6babb37a27a50ea, January 2025). These are 36x32 icons rendered from the game cache, like the RuneProfile icons above. The project README lists OSRS content as Jagex material outside its GPL code licence.
- 288 newer equipment icons from the OSRS Wiki team's DPS calculator (https://github.com/weirdgloop/osrs-dps-calc, cdn/equipment/*.png, matched by item id or, for the cargo crates and a few variants, by exact item name). These are the OSRS Wiki inventory images (CC BY-NC-SA).
All files passed PNG signature checks; none was generated, redrawn or resized. Items whose names repeat (for example the unobtainable Torva copies) share the icon of the variant that has one, through lib/guide-item-images.json, which also lists the six wearables with no icon anywhere (they are not offered in the editor). Guide emojis reuse the site's Discord emoji pack sources (artwork/discord/emojis/manifest.json); no new files.
